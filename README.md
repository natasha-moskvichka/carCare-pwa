# АвтоБорт — PWA приложение для автовладельцев

**АвтоБорт** — это легкое мобильное веб-приложение (PWA), которое помогает водителю вести бортжурнал своей машины: контролировать пробег, записывать расходы на замену масла и обслуживание колодок.

---

## 📂 Структура файлов:

* `index.html` — разметка приложения со стилями по БЭМ.
* `app.js` — вся бизнес-логика приложения, классы и функции отрисовки.
* `manifest.json` — файл настроек PWA, благодаря которому приложение можно установить на экран телефона как обычную программу.
